# Sổ học tiếng Hoa

Trang học tiếng Hoa (chữ Phồn thể, TOCFL) chạy hoàn toàn trên trình duyệt: không cần máy chủ, không cần AI.

- Học và ôn theo lịch (kiểu Anki), 5 mức nhớ: Mới học, Nhớ tạm, Nhớ lâu, Thuộc lòng, Thông thạo
- Tra từ: 7.517 từ TOCFL 2024 + 125.000 mục CC-CEDICT, nét viết động, viết thử
- Thư mục theo band Novice 1 → C, chép chính tả, nhập từ tự học
- Tiến độ lưu trong trình duyệt; dùng Cài đặt › Sao lưu để cất file vào Google Drive

## Nguồn dữ liệu và giấy phép
- Bảng từ TOCFL 2024 (華語八千詞表), SC-TOP, tocfl.edu.tw
- CC-CEDICT, CC BY-SA 4.0 (`data/cedict.tsv` là bản chuyển đổi, cùng giấy phép) — https://www.mdbg.net/chinese/dictionary?page=cedict
- Make Me a Hanzi, nét viết (`data/strokes/`), Arphic Public License — https://github.com/skishore/makemeahanzi
- Hanzi Writer, MIT — https://github.com/chanind/hanzi-writer
- Nghĩa tiếng Việt, mẹo nhớ, ví dụ: soạn riêng cho trang này
